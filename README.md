# BiliFix White

[![Download](https://img.shields.io/github/downloads/Xposed-Modules-Repo/com.xjw.bilifix.in/total)](https://github.com/xiaojiuwo233/BiliFix/releases/latest)
[![stars](https://img.shields.io/github/stars/xiaojiuwo233/BiliFix?label=Stars)](https://github.com/xiaojiuwo233/BiliFix)

哔哩哔哩国际版（白版）已经停更并下架一段时间，app内部分功能已失效。本模块目的是修复一些当前无法正常的功能，同时增加一些本地化功能，满足日常使用。

> 自用模块，写得比较烂，不保证其稳定性，欢迎各位大佬贡献！

### 如果本模块对你有所帮助，欢迎点个[Star](https://github.com/xiaojiuwo233/BiliFix)，十分感谢！
### [关于新版bilibili国际版的说明](https://github.com/xiaojiuwo233/BiliFix/issues/6)

## 兼容性

- 仅支持哔哩哔哩国际白版 `(com.bilibili.app.in)` 3.20.4
- Xposed API 101 或更高版本

## 功能

功能设置入口已集成进应用内设置

### 修复

- 修复新版专栏无法在国际版正常查看的问题
- 修复动态无法显示专栏投稿相关内容
- 修复分区页加载失败
- 修复粉丝与关注列表显示未登录
- 修复钱包页加载失败
- 修复完整用户主页
- 修复无法发送付费表情包
- 修复视频音画不同步

### 增强

- 为部分图片分享菜单 添加系统分享按钮
- 评论区和用户主页显示用户 IP 属地
- 获取由b站自动生成的视频字幕资源（自动生成与自动翻译）
- 评论AI翻译（实验性功能）
- 空降助手：按类别自动跳过社区标记片段，并在进度条显示分类色块。在增强设置的“空降助手”中开启，默认只选择赞助广告；关闭立即停止跳过并移除标记。基于 [BiliSponsorSkip](https://github.com/makabaka11/BiliSponsorSkip) 的只读分段接口，第三方来源见 [说明](THIRD_PARTY_NOTICES.md)。
- 视频小窗贴边收起：双击只在最小与最大两档切换，普通横向视频最大接近屏幕宽度，左右保留约 8 dp 窄边，保持视频比例；拖向屏幕左右边缘收起，点击短圆角把手或向内滑动恢复；在增强设置中开启，关闭立即恢复。收起后显示 22 × 88 dp 半透明灰色把手和细白箭头，不拦截把手上下的区域；沿用原播放器，不暂停视频；当前适配国际白版 3.20.4 普通视频小窗。

## 小窗功能测试构建

```sh
./gradlew -PtestVersionName=0.12.1-test.6 -PtestVersionCode=44 \
  :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

测试版本参数只覆盖本次构建，默认正式版本保持不变。使用支持 modern Xposed API 101 的 LSPatch，将本模块内嵌到原始国际白版 3.20.4；不要同时加载旧的独立小窗模块。签名与已安装应用一致才可保留数据覆盖安装。

真机验证（2026-10-30）：NX888J / Android 16 / b6282，JingMatrix/LSPatch 1.2。已验证左右收起、点击和向内滑动恢复、连续拖动、关闭开关立即还原、重新开启及冷启动保留开关，视频画面持续推进。

当前手机竖屏下，双击在 594 / 1206 px 两档间切换，最大档左右各留 27 px（约 8 dp）；从两侧拉回后保持相同边距。关闭功能会恢复 B 站原始大小偏好，运行期间的两档切换不改写该偏好。把手可见尺寸为 22 × 88 dp，触摸范围为 28 × 88 dp，把手上下不会拦截触摸；灰底不透明度约为 78%，按下时约为 88%。

直播、横竖屏切换和其他 B 站版本尚未实测；横屏与竖向视频的尺寸约束仅通过几何单元测试。最后一次透明度调整已完成构建及安装包校验。

## 空降助手整合

当前分支在原小窗功能基础上加入自动跳过、九类开关和进度条标记，不包含片段提交、投票、用户身份和统计。

- 播放器直接提供当前 aid / cid，并与实际媒体项 ID 比较；不使用首页或网络预加载视频作为当前身份。
- 网络请求在单工作线程执行，只发送视频 BV 号 SHA-256 的前四位，不带 B 站账号 Cookie；按视频及分 P 匹配返回数据。失败不影响播放，1 分钟后允许重试。
- 成功分段最多缓存 16 个视频分 P、有效期 10 分钟。每次播放区间只尝试一次跳转，避免播放器拒绝跳转时反复卡顿。
- 仅播放中每 250 ms 检查时间；暂停、停止或关闭功能后停止定时任务。标记只附着播放器 ViewOverlay，由布局事件更新，不拦截触摸。
- 当前适配国际白版 3.20.4；无对应社区分段的视频不会跳过或显示标记。

测试构建：`./gradlew -PtestVersionName=0.12.1-test.8 -PtestVersionCode=46 :app:testDebugUnitTest :app:lintRelease :app:assembleRelease`。

真机验收（0.12.1-test.8 / code 46，NX888J / Android 16 / JingMatrix LSPatch 1.2）：

- 公共样本 `BV1bfoQYCE3R`（cid `29106111628`）的社区赞助区间为 25.825–72.397 秒；实际日志为 `26009 -> 72397`，整轮只有一次跳过，之后正常播放至结束。
- 关闭赞助类别后，在 00:44 仍可正常播放该片段且无绿色标记；重新开启类别恢复标记和跳过。总开关关闭、开启及冷启动保留设置通过。
- 播放控件展开时的可拖动进度条、控件收起时的细进度条均显示对应区间标记。分段接口曾超时一次，正常播放未中断，自动重试后成功。
- 全部 11 个单元测试通过（空降助手 8 个、小窗 3 个），lint 无错误，安装包签名与原包一致，手机已安装包 SHA-256 与本地产物一致。

范围限制：真实设备目前验证普通视频详情页（包括竖向画面），未完成 Story 连续刷视频、直播、番剧、横屏及小窗播放下空降功能的实测。分 P 隔离已做解析单元测试和播放媒体 ID 校验，尚未做真实多分 P 视频切换验收。社区标记不存在或接口不可用时，保持原播放器行为。
